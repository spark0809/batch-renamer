# BatchRenamer（批量重命名工具）

一个纯 Python 编写的批量文件重命名工具，带图形界面（tkinter）。支持拖拽文件夹、实时预览、一键执行，纯本地运行，不联网。

## ✨ 功能特性

- **添加前缀 / 后缀**
- **删除指定文本**（按文件名精确删除）
- **替换文本**（查找 → 替换为，支持大小写）
- **自动编号**（可自定义起始数字、位数、位置）
- **修改扩展名**（一键批量改后缀）
- **包含子文件夹**（递归处理）
- **扩展名过滤**（如 `jpg;png`，留空为全部）
- **实时预览**（右侧列表显示「原文件名 → 新文件名」）
- **撤销操作**（记录到 `rename_history.json`，出错可回滚）

### 🆕 近期改进（v2 / v3）

- 📂 **拖拽加载**：把文件夹（或文件）直接从资源管理器拖入窗口即可自动加载
- 🟢 **醒目的执行按钮**：顶部超大绿色「▶ 执行重命名」按钮 + 底部浅绿条幅双保险，绝不会找不到
- ⌨️ **快捷键**：`Ctrl+Enter` 直接执行重命名
- 🪟 窗口默认加大，底部操作区不再被裁切

## 🚀 使用方式

### 方式一：直接用 Python 运行（开发 / 调试）

```bash
pip install tkinterdnd2        # 拖拽功能依赖
python renamer_app.py
```

### 方式二：使用打包好的 EXE（推荐普通用户）

1. 下载 `dist/BatchRenamer.exe`
2. 双击运行，无需安装任何东西
3. 选择或拖入目标文件夹 → 配置规则 → 点「▶ 执行重命名」

### 自己打包成 EXE

双击运行根目录的 `build_exe.bat` 即可（需 Python 3.9+）：

```bat
build_exe.bat
```

脚本会自动安装 `pyinstaller` 与 `tkinterdnd2`，并用 PyInstaller 打成单文件、无控制台窗口的 `BatchRenamer.exe`。

## 📖 使用步骤

1. 点击「浏览…」或把文件夹**拖入窗口**
2. （可选）勾选「包含子文件夹」、设置扩展名过滤
3. 在左侧配置规则（前缀 / 后缀 / 删除 / 替换 / 编号 / 扩展名）
4. 右侧实时预览重命名结果
5. 点「▶ 执行重命名」（或按 `Ctrl+Enter`），确认后写盘
6. 如需回退，点「撤销上一次操作」

## 📦 依赖

- Python 3.9+
- `tkinterdnd2`（拖拽支持，已包含在打包脚本中自动安装）
- 其余均为 Python 标准库，无需额外安装

## ⚠️ 注意事项

- 执行重命名前建议先预览确认，操作后可用「撤销」回滚
- 撤销仅针对**上一次**操作，多次误操作请谨慎
- 拖拽功能在部分老旧系统上若失效，可用「浏览…」按钮代替
